## 🚀 Key Features

- **Real-Time Telemetry**: Active stock count tracking across global facilities, live valuation metrics, and safety buffer alerts.
- **Automated Reorder Triggers**: Safety threshold monitoring with 1-click Purchase Order (PO) creation.
- **Spatial Rack Analytics**: Rack-level capacity allocation (e.g. Rack A at 100%, Rack B at 29%).
- **Workflow Pipeline Queue**: Live tracking of orders in *Ready to Process*, *Waiting Stock*, and *In Transit* states.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router) + TypeScript
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Database & ORM**: PostgreSQL / SQLite + Prisma ORM
